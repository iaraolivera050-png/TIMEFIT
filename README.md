# TIMEFIT

Tienda de una página del reloj inteligente TIMEFIT. El mensaje es el de la campaña «Organización y vida cotidiana»: conectar, organizar la rutina y consultar notificaciones.

Abrí `index.html` en el navegador. No hace falta instalar dependencias.

## Qué completar cuando haya datos reales

Todo está en `js/config.js`. Si un campo queda vacío, la página muestra «a confirmar» y no inventa el dato.

- `price`: precio, escrito tal como se quiera mostrar.
- `whatsappNumber`: número con código de país, sin espacios. Con un número cargado, los botones abren WhatsApp con el texto de `whatsappMessage`.
- `socials.instagram` y `socials.facebook`: URL completa de cada red.

Garantía, envío y medio de pago siguen como «A confirmar» en la página. Hay que definirlos antes de redactarlos. No hay pasarela de pago.
